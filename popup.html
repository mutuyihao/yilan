先连接一个模型

一览使用你自己的 API Key，页面内容只会发送给你选择的服务商。

  1. 选择服务商
  2. 填入 API Key
  3. 确认模型

去服务商后台复制 Key 时弹窗会自动关闭，完整页面不会。

在任意网页按 AltS 或用右键菜单，也能直接总结。 也可以在网页上右键，选择“用一览总结此页”。

隐私与控制
无痕模式 仍会把当前页面内容发送给模型，但不会写入本地历史记录。
默认写入历史 关闭后，新的总结结果只保留在当前侧栏，不进入历史记录。

高级 提示词与长文并发
长文分段摘要的并行请求数；1 为逐段串行，默认 2，网关限流严格时可调低。
